# 与 macOS OShell 同步配置

两端通过共享加密文件交换配置，各自保留本机数据。不要共用本机数据目录，也不要用云盘同步整个程序目录。

## 首次接入

1. 将所有设备升级到支持共享协议 v2 的版本，并设置、解锁相同主密码。WebDAV 登录密码与主密码用途不同。
2. 在已有数据的 OShell 上启用 WebDAV 或同步目录，先完成一次同步。保存的密码须使用主密码保护；本机密钥保护的密码先转换。
3. 在 Desktop 的“设置 → 同步”选择“同步目录”或“WebDAV”，填写目标后点击“应用”。WebDAV 填 HTTP / HTTPS **目录地址**，不要填文件 URL；目录会自动识别空目录或已有配置。
4. 首次接入选择使用共享数据，或合并本机会话并确认差异。首次替换会备份本机配置。
5. 每台设备分别保存同步地址和登录凭据；离线时使用本机副本，联网并解锁后再同步。

WebDAV 新目标会自动使用或创建 `oshell` 子目录；地址已以 `oshell` 结尾时不再嵌套。旧地址下已有 `oshell-vault.json` 则继续沿用，不迁移文件。“测试连接”也可能创建子目录，成功后显示实际同步目录；父目录须存在且账号有相应权限。

## 同步范围

默认只同步会话、目录、快捷链接、代理和加密密码。首次合并保留两侧独有资料，冲突仍需确认；私钥只同步路径，不上传文件。

可另外勾选“客户端设置与高亮规则”“快速命令”“默认会话属性”。未勾选类别保留本机和远端原值，不因本机修改而上传。切换范围后重新确认已有数据，旧同步基准及冲突草稿归档保留。共享字段合同不变。

同步策略仅保存在本机：自动或手动、启动检查、修改后等待、定时检查、失败重试。检查及重试间隔允许 0（关闭）或 15–86400 秒，修改后等待为 1–300 秒。

本机密钥、WebDAV 凭据与证书信任、主机指纹、日志、同步基准、侧栏、标题、置顶、关闭确认、图片粘贴记忆和选词设置、命令历史、传输记录、续传检查点不参与同步。

| 目标 | 加密文件 |
| --- | --- |
| WebDAV | 自动选定目录中的 `oshell-vault.json`（新目标通常为 `oshell/oshell-vault.json`） |
| 共享目录 | `configuration.json` |

两端读取共享版本 1 / 2，写入版本 2。未知版本或字段会拒绝应用和覆盖，请先升级全部设备。会话归档 `OShell.sessions` 的 1–4 版本与共享版本无关。

## 冲突与故障

头部同步按钮打开独立状态窗口，可立即同步、取消或进入配置，各窗口展示同一任务状态。顶部卡片显示已保存配置、最近成功时间及待处理问题；未应用的草稿不会用于手动同步。成功和无变化不弹窗，自动失败保留在状态卡片中。

切换同步方式或目录后立即生效，本机工作数据目录不变，旧共享文件保留。目录同步成功仅表示本机目录文件已对齐，不能证明云盘已上传。旧版待生效目录仍需按原流程重启迁移，或取消后重新选择。

显式填写 `http://` 即可使用 HTTP，无需额外开关。HTTP 会明文传输 WebDAV 账号密码，建议只用于可信网络；共享文件仍由主密码加密。所有重定向（包括 HTTPS 降级到 HTTP）均拒绝。

HTTPS 默认使用系统证书校验。自签名服务可点击“查看 / 信任服务器证书”，核对主体、颁发者、有效期和 SHA-256 指纹后显式信任并应用。信任仅绑定该主机、端口和完整证书，其他设备须重新确认；证书更换、过期或尚未生效会停止连接。IP 直连允许显式名称和用途例外，普通域名仍严格校验。HTTP 地址不显示证书控件。

- 不同会话的修改可合并；同一会话并发修改需要确认，未解决前不覆盖远端。
- 上传成功后若本机又有修改，保留新修改并在下一轮继续合并；尚未应用的远端新增会话不会丢失。上传失败不会推进同步基准。
- WebDAV 必须支持强 ETag 和条件写入。目标删除、密码错误、损坏或版本不支持时，保留本机数据并停止覆盖。
- 共享目录和云盘不保证跨设备原子写入。多设备同时编辑建议使用合规 WebDAV；出现云盘冲突副本时先保留并处理。

字段、加密和验收规则见 [共享配置协议 v2](configuration-protocol-v2.md)。
