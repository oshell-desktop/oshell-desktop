### 2026-10-26 SF-F14 审查修复与本机复验

本轮五项缺陷均归 SF-F14，不新增编号或扩大功能边界：缓冲区满时取消被锁阻塞、选择文件期间远端取消不生效、上传被跳过/拒绝却报成功、取消后原生选择框残留、Windows 对话框错误被吞掉及部分所选文件静默丢失。

- 取消使用独立的原子会话引用，不再等待缓冲区背压锁；原始连续 CAN 在入站阶段识别，覆盖跨读分块与文件选择等待期。
- ZSKIP、ZABORT、ZFERR 分别作为逐文件跳过、批次取消、远端文件错误处理。批次结果保留跳过的文件名；正常结束但有跳过时不显示全部成功，也不向已恢复的 shell 额外发送取消字节。

- Windows COM 创建、配置、显示与读取结果保留 HRESULT；只有明确用户取消按取消处理，部分结果出错时拒绝返回不完整的文件集合。
