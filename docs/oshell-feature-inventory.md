范围按以下规则执行：

1. **固定参考版本。** 当前提交、应用生产入口和本表约定共同界定范围；不自动追随 OShell、SwiftTerm、Ghostty、Unicode、Kitty 或操作系统后续新增能力。
2. **固定功能身份。** 后续补充样例、错误处理、协议参数、平台事件和回归，必须归到已有 SF 条目。移动分类、拆表或添加测试不能改变目录计数、重排既有编号或制造完成进度。
3. **区分缺陷与新增。** 可证明违反现有条目预期的行为是原范围内缺陷，继续修复；无需为了修复已授权功能的边界另求批准。新的产品入口、协议、平台、数据模型或独立能力属于范围变更，获得用户明确授权后才纳入。
4. **原版遗漏有记录。** 发现固定源码已有、但表中没有表达清楚的能力，先写明源码/生产入口及可归属条目。能归属的补充说明和证据，不能擅自新增功能编号；确实无法归属的列为“基线遗漏待决议”，说明纳入影响，不能静默扩大或静默删除原有复刻要求。
5. **平台机制不扩张。** Touch ID 及苹果专属授权明确排除；不因此自动追加 Windows Hello。全屏、认证保护、更新等通用结果仍须实现，AppKit/Metal/Sparkle 仅替换实现机制。Desktop 已有额外功能不自动变为 OShell 复刻要求。
6. **待验证不等于排除。** 缺少 macOS、Linux 或真实键鼠验证，只能记“待验收”；已有明确缺陷不能通过改边界、删用例或降低表述掩盖。原版缺陷需要有意修正时，记录差异、原因和替代预期，不盲目复制越界/损坏行为。
7. **不设无限终点。** 不把“穷举所有输入组合”“兼容最新完整标准”“继续寻找可能存在的边界”作为完成条件。按约定验收结果、固定用例集和已知可复现问题验收；只有新的具体证据才重开已通过条目。

## 验收与变更记录方法

每个实际复刻任务先引用 SF 编号，再列出有限的验收用例。适用维度为：正常入口与结果、取消/失败、对象关闭/迁移、保存/重开、共享往返、目标平台交互。每条用例写出具体输入、操作和预期；不要求对所有维度取笛卡尔积，不适用的维度说明原因。

| 记录类型 | 必填内容 | 对功能基线的影响 |
| --- | --- | --- |
| 实现任务 | SF 编号、具体差异、实现入口、计划验证的场景 | 不新增功能 |
| 缺陷/回归 | SF 主归属、固定源码证据、复现步骤、实际/预期、回归及平台结果 | 不新增功能；修复已有约定 |
| 平台差异 | SF 编号、原版机制、等价结果、不能等价的具体行为及原因 | 不能仅凭平台名称排除通用功能 |
| 基线遗漏 | 固定源码生产入口、现有条目为何不能容纳、影响和拟归属 | 保留待决议，不能偷偷纳入或删掉 |
| 新需求/升级 | 来源版本、增加/改变的能力、影响条目、验收变化、用户授权 | 授权后修订基线版本，保留变更记录 |
| 验收结果 | SF 编号、实际执行用例、平台/版本、结果与日志位置、剩余差异 | 只报告已执行证据，不用文件/测试数量换算完成率 |

条目状态采用“未核查 / 差异已定位 / 实现中 / 待验收 / 已验收 / 平台专属排除”。标记已验收要求其约定用例通过、已知有效缺陷闭合、所需平台证据齐全；代码存在或本地单测通过不足以代替。程序改动还应执行仓库规定的本地便携包验证；本次文档整理不触发重新打包。

跨域问题只确定一个主归属，其他条目作为关联。例如“跨窗口迁移后图片粘贴发到旧终端”主归 SF-M05，关联 SF-W08；“缩放后 OSC 133 点击错行”主归 SF-I26，关联 SF-I15；“未知字段导致同步丢配置”主归 SF-Y17，关联 SF-Y12。一个问题不计成多个新增功能。

本次基线记录：2026-10-24 建立 scope-1，将原清单 161 行逐项补充范围与验收要求；未新增产品能力，未改变原版参考提交，未认定任何条目完成实机验收。后续范围修订需在此追加日期、原因、受影响 SF 编号和授权依据。

## 产品对象与作用范围

OShell 可以理解为“会话资料库 + 多窗口终端工作区 + 文件管理 + 凭据与同步”四部分。准确区分以下对象，是梳理功能的前提。

| 对象 | 含义与作用范围 |
| --- | --- |
| 会话配置 | SSH / SFTP / FTP / 本地类型的保存资料；名称、目录、主机、端口、用户、凭据与连接选项。不是正在运行的连接 |
| 会话目录 | 配置分类树；与服务器的文件目录、文件初始目录无关 |
| 快捷引用 | 指向原会话的引用；独立名称、位置、排序，连接时读取源会话最新配置 |
| 终端分屏 | 一个运行中的终端、连接或本机工具提示符；拥有自己的输出、历史、搜索和输入状态 |
| 标签 | 可以包含多个终端分屏；关闭整个标签与关闭当前分屏不同 |
| 标签组 | 组织标签和布局、显隐及发送范围；不等同于保存会话的目录 |
| 窗口 | 独立工作区；标签、分屏、发送目标与同步输入局限于本窗口；会话资料和应用配置跨窗口共享 |
| 文件标签 | 独立文件会话、远端目录、限速、传输记录和续传状态；可与终端复用底层 SSH 连接 |
| 共享配置 | 经主密码加密交换的跨设备资料；各设备仍保留独立本机工作副本 |

证据：[核心模型](../validation/oshell-reference/Sources/OShellCore/Models.swift)、[原版使用指南](../validation/oshell-reference/docs/usage.md)、[发送范围定义](../validation/oshell-reference/Sources/OShellCore/QuickSendScope.swift)。

## 数据持久化与同步边界

| 数据 | 持久化/共享范围 |
| --- | --- |
| 会话、目录、引用、代理、加密密码 | 本机持久化；默认共享范围 |
| 客户端偏好、高亮、快速命令、默认会话属性 | 本机持久化；相应类别勾选后共享；平台专属项仍例外 |
| 私钥 | 资料可记录路径；文件内容不随同步或归档上传 |
| 主机指纹、本机加密密钥、Touch ID 记录 | 本机身份/信任资料，不参与共享配置 |
| WebDAV 登录、证书信任、目标地址、同步策略与基准 | 各设备独立管理，不作为共享会话资料传播 |
| 侧栏、置顶、本机标题、关闭确认、选词分隔符、图片提醒 | 本机偏好；不能因为开启“客户端设置”就一概共享 |
| 手工发送目标、窗口组选择、同步输入状态 | 当前窗口运行状态；不作为可恢复的跨设备目标列表 |
| 本机提示符历史 | 每分屏内存，不是服务器 Shell 历史，不参与同步 |
| 传输记录和续传检查点 | 当前文件标签内存；重启不自动恢复 |
| 终端输出历史 | 当前终端缓冲；主动日志可落盘，不等于支持重启恢复连接/全部工作区 |
| 图片文件 | 本地缓存或远端上传文件；不进入共享配置，提醒记忆与图片本体分别处理 |

共享字段与实际启用同步范围并不相同。具体字段以[协议 v2](configuration-protocol-v2.md)及其可执行合同为准。

| 终端协议 | 完整状态机、查询、重置、字节分块、宽度/重排和复杂组合的差分验收 |
| 图像与排版 | ICC/HDR、CMYK/Lab、DPI、相对图片、资源预算、BiDi、双宽/双高、真实双端像素 |
| 真实输入 | Windows/Linux 物理布局、死键/输入法、数字键盘及增强键盘的完整事件链 |
| 窗口交互 | 真鼠标跨窗口拖动、悬停焦点、取消/隐藏/移除时事件归属、复杂分屏和焦点切换 |
| 传输 | ZMODEM 中断/收尾字节及延迟、传输期本地交互与输入隔离的完整场景 |
| 生命周期 | 多窗口反复开关、长时间空闲/输出的资源曲线，正常退出交互；隐藏实例清理不等于退出验收 |
| 平台升级 | 真实 Linux 桌面运行、安装与升级回滚；交叉编译不能替代 |

后续验收应在这 13 个稳定功能域中逐项补充“入口 → 正常操作 → 取消/失败 → 生命周期 → 持久化/跨端 → 平台证据”。新发现的协议或边界问题归入对应功能域，不增加“功能总数”来表达进度。
