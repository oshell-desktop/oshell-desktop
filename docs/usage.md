# 使用指南

## 会话管理

头部“侧栏”按钮或 `Ctrl+Shift+B` 显示 / 隐藏会话树；“设置 → 选择与侧栏”可修改快捷键。搜索支持名称、主机、用户名、端口和目录，双击或 Enter 连接。

侧栏搜索框下方和右键菜单提供“全部展开 / 全部收缩”。搜索时只操作匹配结果，清空搜索恢复原目录树的展开状态；不会修改会话配置。

侧栏与会话管理共用右键操作：连接、文件管理、属性、复制粘贴、重命名、移动、删除、导入导出。F2 重命名，Enter 保存，Esc 取消。会话管理列表失去编辑焦点也会取消重命名。

会话管理和侧栏使用统一大小的文字标识：SSH 蓝色、SFTP 绿色、FTP 橙色，适配浅色和深色主题。本地终端、目录保留电脑和文件夹图标；快捷引用使用源类型图标和链环角标，悬停可查看目标类型及来源，`Links` 下的实际会话仍显示自己的类型。

会话管理中用 `Ctrl+C` 复制所选会话，`Ctrl+V` 粘贴到当前目录，支持多选。副本使用新 ID，同名自动加后缀，保存的密码会重新绑定身份。剪贴板仅存本次运行的临时引用；跨应用迁移使用导入导出。输入框内仍按普通文本复制粘贴。

终端和文件标签可拖动排序；终端标签可拖到其他窗口的内容区或标签栏，按插入标记合并到指定标签组，空窗口也可接收。拖到窗口外空白处松开，会在松手位置创建新窗口，继续使用原连接、分屏和历史；Esc 取消。移走最后一个标签后原窗口关闭，文件管理连接和传输继续保留。文件窗口按 Esc 最小化，Ctrl+W 关闭，传输中关闭会提示确认。

根目录的会话和目录可右键置顶，重命名保留，移入子目录后取消。侧栏支持 Ctrl 多选、Shift 范围选择。标题可选择会话名称、Shell 集成、主动探测或被动识别；复制继承本机标题选择，分屏标签汇总名称。悬停标签可逐项复制连接详情，不抢占输入焦点。

“全心专注”默认 Ctrl+Alt+Shift+F，隐藏终端小标题和发送栏，退出后恢复布局与草稿；可在本机设置中修改快捷键。关闭标签确认可单独关闭。

## 终端

| 操作 | 默认方式 |
| --- | --- |
| 跳到行首 / 行尾 | Ctrl+A / Ctrl+E |
| 删除光标前一个词 | Ctrl+W |
| Windows 替代键 | Home 同 Ctrl+A；Ctrl+Backspace 同 Ctrl+W |
| Windows 全选 / 关闭分屏 / 关闭标签 | Ctrl+Shift+A / Ctrl+Alt+W / Ctrl+Shift+W |
| 按分隔符选词 | 首次双击 |
| 按空白扩大选择 | 同一位置再次双击，或 Shift+双击 |
| 选择当前行 | 连续三击 |

Shell 编辑键的实际行为由当前远端程序决定。可在“设置 → 键盘快捷键”修改替代键；它们不影响普通输入框。远端程序启用鼠标跟踪时，按住 Shift 使用本地选择。

“设置 → 选择与侧栏”可调整选词分隔符、Shift 方式、自动复制和空白清理。主题设置可启用黑白自动对比光标，也可手动设置颜色。Windows / Linux 打包运行库支持歧义字符双宽；该选项在新建终端时生效。

本机 `oshell>` 提示符支持常用行编辑、词间移动及 Tab 命令名补全。每个提示符保留最近 100 条命令：上下键浏览，Ctrl+R / Ctrl+S 搜索，Ctrl+G 恢复草稿，Esc 取回结果编辑，Enter 执行。历史不记录 SSH 密码或工具启动后的交互输入；不解析完整 Shell 脚本、管道和重定向。

粘贴剪贴板图片时，本地终端保存 PNG 缓存，SSH 复用当前认证通过 SFTP 上传到私有目录，再只向原终端插入已转义路径，不自动回车、不广播。支持 PNG、JPEG、GIF、BMP、TIFF、WebP；转换后最多 20 MiB。可记住本机或指定 SSH 会话的选择，在设置中逐项或全部恢复确认。换身份、跳板、代理或连接状态改变时重新确认。

需要远端主机标题识别时，参见 [Shell 集成](../resources/shell-integration/README.md)。

会话属性中的“保活”可设置 SSH 心跳和空闲字符串，保存后新连接或重连生效。要立即调整当前连接，右键标签 →“当前会话属性…”；例如勾选空闲发送、间隔 `30` 秒、文本 `ls \n`。应用后重新计时，终端输入或输出会重新开始空闲计时，`rz/sz` 传输期间暂停发送；SSH 心跳本身不会重置空闲计时。

## 文件传输

从对应 SSH 会话打开文件管理，各文件标签独立保存连接、限速和传输记录。限速按钮支持预设和自定义；SFTP / FTP 即时生效，SCP 下次传输生效。远端 `rz` 用于上传，`sz` 用于下载。

双击传输记录查看路径、结果和错误。同一身份重连保留记录，更换身份或关闭标签清除；最多保留 500 条已结束记录，未完成记录额外保留。

SFTP 普通文件支持暂停、继续和重试，连接失效时按原身份重连。续传会校验源文件及已传片段，完成后才将 `.oshell-*.part` 发布为最终文件，不覆盖已有目标。上传续传需要服务器允许读取临时片段。

目录、FTP、SCP 不支持续传。暂停后，批次中未开始的项目需重新选择；关闭标签、退出程序或清除失败记录后不能恢复检查点，临时片段可在确认不再需要后自行删除。

## 配置与数据

- Windows 单文件版：数据保存在 EXE 同级目录，忽略 `OSHELL_DATA_DIR` 和旧位置记录。
- 非便携模式：Windows 默认 `%APPDATA%/oshell-desktop`；Linux 默认 `${XDG_CONFIG_HOME:-~/.config}/oshell-desktop`。
- “设置 → 存储”可更改非便携版位置；完全退出并重启后迁移，旧数据保留。
- 私钥路径可以同步，私钥文件不会上传；侧栏状态、选词设置、命令历史、传输记录和续传检查点不参与同步。

迁移时保留完整数据目录，包括配置、凭据、密钥和主机指纹。同步接入见 [配置同步](shared-configuration.md)，升级及恢复见 [更新与发布](updates-portable.md)。
