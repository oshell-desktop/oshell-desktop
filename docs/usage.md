# 使用指南

## 主窗口与工具栏

头部从左到右依次是会话入口、分屏与标签排列、搜索与记录、工具与 MCP，以及右侧的会话属性、全局代理、同步、更新和设置。会话属性按钮的主体编辑当前 SSH 会话，右侧箭头可编辑默认属性或从目录选择其他会话。选择快捷引用时打开源会话属性。

“分组排列”为每个标签显示独立标签栏。“分屏排列”让多个会话共用一条标签栏，支持左右、上下和瓷砖布局。选择“合并为选项卡”可恢复单标签显示。

工具栏在宽度低于 1180 点时收起主要按钮的文字，低于 980 点或高度低于 500 点时收起整行。窗口恢复到至少 1028 × 548 点时重新显示。Windows 和 Linux 可以从标签栏的“更多”进入会话、工具及其他菜单。

在“设置 → 窗口”勾选“固定启动窗口大小”，填写内容区宽高或点击“使用当前窗口大小”，再点“应用”。固定尺寸对新建窗口和下次启动生效，关闭固定尺寸时沿用普通窗口大小。该偏好仅保存在本机。

## 会话管理

“快捷连接”按会话管理器的顺序展示已启用快捷连接的会话。根目录置顶项优先，同级先目录后会话，名称中的数字按数值排序，例如 `node2` 排在 `node10` 前面。“快速切换 / 连接”中的已保存会话也使用这一名称顺序。

首次使用时会话栏默认收起，已有安装沿用保存的选择。“设置 → 常规 → 展开左侧会话栏”设置当前窗口及以后新窗口的初始状态。头部“侧栏”按钮、`Ctrl+Shift+B` 和“设置 → 选择与侧栏”可单独切换当前窗口。搜索支持名称、主机、用户名、端口和目录，双击或 Enter 连接。

侧栏搜索框下方和右键菜单提供“全部展开 / 全部收缩”。搜索时只操作匹配结果，清空搜索恢复原目录树的展开状态；不会修改会话配置。

侧栏与会话管理共用右键操作：连接、文件管理、属性、复制粘贴、重命名、移动、删除、导入导出。F2 重命名，Enter 保存，Esc 取消。会话管理列表失去编辑焦点也会取消重命名。

会话管理和侧栏使用统一大小的文字标识：SSH 蓝色、SFTP 绿色、FTP 橙色，适配浅色和深色主题。本地终端、目录保留电脑和文件夹图标；快捷引用使用源类型图标和链环角标，悬停可查看目标类型及来源，`Links` 下的实际会话仍显示自己的类型。

会话管理中用 `Ctrl+C` 复制所选会话，`Ctrl+V` 粘贴到当前目录，支持多选。副本使用新 ID，同名自动加后缀，保存的密码会重新绑定身份。剪贴板仅存本次运行的临时引用；跨应用迁移使用导入导出。输入框内仍按普通文本复制粘贴。

终端和文件标签可拖动排序；终端标签可拖到其他窗口的内容区或标签栏，按插入标记合并到指定标签组，空窗口也可接收。拖到窗口外空白处松开，会在松手位置创建新窗口，继续使用原连接、分屏和历史；Esc 取消。移走最后一个标签后原窗口关闭，文件管理连接和传输继续保留。文件窗口按 Esc 最小化，Ctrl+W 关闭，传输中关闭会提示确认。

根目录的会话和目录可右键置顶，重命名保留，移入子目录后取消。侧栏支持 Ctrl 多选、Shift 范围选择。标题可选择会话名称、Shell 集成、主动探测或被动识别；复制继承本机标题选择，分屏标签汇总名称。悬停标签可逐项复制连接详情，不抢占输入焦点。

复制标签时，副本紧挨源标签右侧并获得焦点。关闭当前标签时，优先选中同一标签栏的左邻。关闭首个标签时，选中余下的第一个。关闭后台标签保留当前焦点。

“全心专注”默认 Ctrl+Alt+Shift+F，隐藏终端小标题和发送栏，退出后恢复布局与草稿；可在本机设置中修改快捷键。关闭标签确认可单独关闭。

## 终端

| 操作 | 默认方式 |
| --- | --- |
| 跳到行首 / 行尾 | Ctrl+A / Ctrl+E |
| 搜索当前终端的输出和历史 | Ctrl+F，Esc 返回终端（Windows / Linux） |
| 提交当前命令 | Enter、Shift+Enter 或 Ctrl+Enter |
| 切换专注全屏 | Alt+Enter 或 F11（Windows / Linux） |
| 向左 / 向右移动一个词 | Alt+← / Alt+→（同 Alt+B / Alt+F） |
| 删除光标前一个词 | Ctrl+W |
| Windows 替代键 | Home 同 Ctrl+A；Ctrl+Backspace 同 Ctrl+W |
| Windows 全选 / 关闭分屏 / 关闭标签 | Ctrl+Shift+A / Ctrl+Alt+W / Ctrl+Shift+W |
| 按分隔符选词 | 首次双击 |
| 按空白扩大选择 | 同一位置再次双击，或 Shift+双击 |
| 选择当前行 | 连续三击 |

在普通终端命令行，Alt+← 和 Alt+→ 分别发送 Meta-B 和 Meta-F，使用 Bash 默认键位即可按词移动。程序启用备用屏幕、应用光标模式或 Kitty 增强键盘协议时，直接接收原方向键。

Shell 编辑键的实际行为由当前远端程序决定。可在“设置 → 键盘快捷键”修改行首、删除前一个词的替代键。远端程序启用鼠标跟踪时，按住 Shift 使用本地选择。

在快速发送栏或多行撰写框中，Shift+Enter 和 Ctrl+Enter 都执行“发送”，沿用选定的目标与“追加回车”设置。多行撰写框中单独按 Enter 可换行。

“设置 → 选择与侧栏”可调整选词分隔符、Shift 方式、自动复制和空白清理。“设置 → 主题与配色”可分别设置光标和光标文字的颜色。Windows / Linux 打包运行库支持歧义字符双宽；该选项在新建终端时生效。

本机 `oshell>` 提示符支持常用行编辑、词间移动及 Tab 命令名补全。每个提示符保留最近 100 条命令：上下键浏览，Ctrl+R / Ctrl+S 搜索，Ctrl+G 恢复草稿，Esc 取回结果编辑，Enter 执行。历史不记录 SSH 密码或工具启动后的交互输入；不解析完整 Shell 脚本、管道和重定向。

粘贴剪贴板图片时，本地终端保存 PNG 缓存，SSH 复用当前认证通过 SFTP 上传到私有目录，再只向原终端插入已转义路径，不自动回车、不广播。支持 PNG、JPEG、GIF、BMP、TIFF、WebP；转换后最多 20 MiB。可记住本机或指定 SSH 会话的选择，在设置中逐项或全部恢复确认。换身份、跳板、代理或连接状态改变时重新确认。

需要远端主机标题识别时，参见 [Shell 集成](../resources/shell-integration/README.md)。

会话属性中的“保活”可设置 SSH 心跳和空闲字符串，保存后新连接或重连生效。要立即调整当前连接，右键标签 →“当前会话属性…”；例如勾选空闲发送、间隔 `30` 秒、文本 `ls \n`。应用后重新计时，终端输入或输出会重新开始空闲计时，`rz/sz` 传输期间暂停发送；SSH 心跳本身不会重置空闲计时。

从堡垒机网页打开 SSH 后，右键标签选择“当前会话属性…”，调整保持活动并点“应用并保存”。空闲发送立即生效，SSH 心跳和 TCP 保活从下次连接生效。OShell 按堡垒机地址和端口保存到本机，后续即使换用其他登录票据也会沿用。

在持续滚动的终端中，按住鼠标左键可暂停显示并选择文字。松开时，启用了自动复制的会话先复制选区，再继续显示输出。支持鼠标操作的远程程序仍可直接接收鼠标事件。

在“设置 → 时钟”启用浮动时钟后，可勾选“仅全屏时显示”。普通窗口会隐藏时钟并停止计时刷新，设置页仍提供预览。此选项保存在本机。

全局代理会接在会话路线前面。比如全局路线为 A → B、会话路线为 B → C，新连接会经过 A → B → C。路线顺序冲突或合并后超过八级时，连接界面会显示原因。

SSH 报告主机密钥变化时，在失败页点击“清理旧主机密钥…”，通过可信渠道核对新旧指纹后选择“清理并重新连接”。再次连接时仍会提示确认新密钥。

## 文件传输

从对应 SSH 会话打开文件管理，各文件标签独立保存连接、限速和传输记录。限速按钮支持预设和自定义；SFTP / FTP 即时生效，SCP 下次传输生效。远端 `rz` 用于上传，`sz` 用于下载。

双击传输记录查看路径、结果和错误。同一身份重连保留记录，更换身份或关闭标签清除；最多保留 500 条已结束记录，未完成记录额外保留。

SFTP 上传和下载会将断点记在本机。关闭标签或重启后，以同一 SSH 身份重新传输相同源路径和目标路径即可恢复。遇到同名目标，选择“续传”会逐字节校验已有内容，完整一致的文件直接跳过。对目录选择“续传”会逐文件恢复。“保留两份”会将新目标命名为 `.1`、`.2` 等。

缺少旧断点记录时，在 SFTP 文件列表选中远程旧片段，点“旧片段续传… → 上传到选中的远程片段…”并选择本地源文件。下载时选中远程源文件，点“旧片段续传… → 下载到本地片段…”并选择本地同名文件或 `.oshell-*.part`。前缀不一致会停止，上传校验需要服务器允许读取片段。

## 配置与数据

- Windows 单文件版：数据保存在 EXE 同级目录，忽略 `OSHELL_DATA_DIR` 和旧位置记录。
- 非便携模式：Windows 默认 `%APPDATA%/oshell-desktop`；Linux 默认 `${XDG_CONFIG_HOME:-~/.config}/oshell-desktop`。
- “设置 → 存储”可更改非便携版位置；完全退出并重启后迁移，旧数据保留。
- 私钥路径可以同步，私钥文件不会上传；侧栏状态、选词设置、命令历史、传输记录和续传检查点不参与同步。

迁移时保留完整数据目录，包括配置、凭据、密钥和主机指纹。同步接入见 [配置同步](shared-configuration.md)，升级及恢复见 [更新与发布](updates-portable.md)。
