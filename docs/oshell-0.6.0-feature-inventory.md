# OShell 0.6.0 功能清单与版本变化

整理日期：2026-10-29。固定来源：官方 [`v0.6.0`](https://github.com/oshell-desktop/oshell/tree/18770fee58770c54aa33db574b646e49ae18e208)，提交 `18770fee58770c54aa33db574b646e49ae18e208`。对照版本为 0.2.92 / `3f4efd9c70c82323f4e20180117c928227000580`。本机只读分析快照：`validation/oshell-0.6.0/`，旧参考工作目录仍保持原提交。

本清单描述 **OShell 原版 0.6.0 的能力**，不是 Desktop 实现差异清单或功能验收通过声明。用户本次授权重新梳理；没有因此把 Desktop 的 `OShell-0.2.92-scope-1` 改成新版复刻目标。旧 [161 项基线](oshell-feature-inventory.md)及验收状态不变。

## 阅读结论

- 共 **14 个功能域、176 个调查条目**：原 161 项保持一对一对照，另列 MCP 控制与审计 15 项。新版使用 `V060-*` 调查编号，不新增或重排旧 `SF-*`。176 是清单槽位数，不是开发任务数或完成率分母。
- 原 161 项中 **34 项记录范围、行为或机制变化**，其余 127 项沿用旧源码结论并比对版本文件；“沿用”不表示所有关联函数或底层依赖完全未变。CSV 分列入口文件是否变化及证据方式。
- 当前是外部 Agent 的 **MCP 控制中心**。0.3.x 内置模型聊天、模型供应商/API 密钥配置、聊天命令卡不是 0.6.0 当前功能；0.6.0 还移除旧 AI 历史兼容入口。代码中个别 `AI` 类名是面板布局沿用，不能据此认定仍有内置 AI 聊天。
- 新能力集中在全局代理、Finder 目录入口、文件管理停靠/终端命令模式、rsync、用户字体库及可选字体附件同步/备份、MCP 授权/审批/PTY 控制/加密审计与回放。
- 安装包不再内置 Cascadia、DejaVu 或 Nerd Font；系统字体与用户导入字体替代。原版主线最低 **macOS 15**，仅 arm64/amd64 两种 DMG。

## 证据与边界

基于固定标签源码、入口调用和旧/新 Git 树差异整理，不只依据 README 或发布说明。新增及显著改变路径已直接阅读；沿用条目继承 [0.2.92 源码分析](oshell-source-analysis.md)，不冒称本轮把全部源码重新逐行审计。每行提供 **0.6.0 固定提交**的文件链接；不沿用旧版行号。文件存在、哈希一致或上游自述测试通过都不等于本轮运行验证通过。

本轮环境为 Windows，未启动 macOS 原版、未执行 Swift 核心/UI/真实客户端验收或双端互通，未重新检查 Desktop 的逐项实现。缺少这些证据应记录待验，不能写成已通过。原条目“限定边界”中继承的移植排除约定不是上游缺失能力的证明；终端旧版已定位缺陷是否仍在 0.6.0，需要相应新版本专项证据。

可筛选明细：[CSV](oshell-0.6.0-feature-inventory.csv)。版本与快照核对：[source-provenance.json](../validation/oshell-0.6.0/source-provenance.json)。生产文件变动：[production-delta.csv](../validation/oshell-0.6.0/production-delta.csv)。基础说明可参阅固定版本 [CHANGELOG](https://github.com/oshell-desktop/oshell/blob/18770fee58770c54aa33db574b646e49ae18e208/CHANGELOG.md) 与 [MCP 使用文档](https://github.com/oshell-desktop/oshell/blob/18770fee58770c54aa33db574b646e49ae18e208/docs/agent-control.md)，结论以以下生产实现为依据。

## 必须单独看待的边界变化

| 变化 | 已确认的 0.6.0 行为 | 不可扩大推论 |
| --- | --- | --- |
| MCP 替代内置 AI | 外部客户端负责模型，OShell 管授权、现有 PTY、审计 | 不等于内置聊天/供应商接入仍存在，也不能把客户端其他工具算作 OShell 能力 |
| 全局代理 | 仅覆盖 OShell 新 SSH 系连接路线，本机开关 | 不是系统 VPN/全局网络代理，不改变已有复用通道 |
| 文件管理模式 | 内置停靠/窗口或当前终端命令，命令启动需确认 | 不自动安装 yazi，不用终端模式替换所有 SFTP/上传入口 |
| rsync | 同名更新、保留目标额外文件，片段可复用 | 不是删除式镜像，不等同 SFTP 暂停/续传记录，也不表示跨重启自动恢复 |
| 字体附件 | 默认关闭，明文独立 fonts/，目录/WebDAV/备份分别承载 | 不进入加密共享 v2，不证明 Desktop 已能导入/显示/合并这些字体 |
| 字号缩放 | 每 pane 临时 8–40，幅度累计、不转发 TUI | 不修改全局字号模型/共享偏好；Desktop 已有缩放不能直接当作参数完全一致 |
| 时钟 | 每窗口一个 | 不再按每个终端 pane 重复显示 |
| 分屏排列 | 窗口级标签排列，与分组排列分开 | 不等于“重排当前标签内的 pane”；需核对实际作用对象 |
| 系统与资源 | macOS 15+ 两架构；移除随包字体、旧系统兼容层 | 不自动取消 Desktop 平台支持或既有内置字体 |
| 审计导出 | 本机记录可加密导出，活跃/未封口不可作为完整记录导出 | 未发现外部导出文件导入/回放入口，不列为现有能力 |
