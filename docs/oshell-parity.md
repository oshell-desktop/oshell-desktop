## 固定范围与计数口径

此前将越来越细的边界、缺陷修复和回归场景追加为同级编号，导致清单从功能目录变成了功能与核查记录的混合表。“224 项”是这些记录的行数，不是 OShell 的功能总数，也不是剩余工作量。这一计数方式停止使用。

验收范围固定为上述 v0.2.92 源码中的全部非 macOS 专属功能，按以下已有类别组织。新的边界发现归入既有类别和条目，补充状态、差异与证据；历史编号保留以便追溯，不再追加编号来表示进度。

细分范围统一见 [OShell 功能基线 scope-1](oshell-feature-inventory.md)：13 个功能域、161 个固定目录条目，各项具有 SF 编号、包含范围、限定边界与验收结果要求。161 是目录槽位数，不是剩余工作量或完成率分母。后续实现和缺陷应引用 SF 编号，旧 S/I 等编号仅作为历史证据；本文件历史记录中的“全部控制序列”等表述受固定参考源码的生产入口及该基线约束，不代表最新标准或所有 Vendor 接口。新增协议、平台或独立功能须单独记录范围变更，不能在回归过程中自动纳入。

排除按用户可用的功能判断，不能按 Swift 文件名、AppKit 调用或苹果框架判断。目前明确排除 Touch ID 本身及其苹果专属授权机制；主密码、凭据保护与迁移、全屏、窗口和菜单操作、检查更新、下载、安装及失败恢复均在对齐范围内。Windows / Linux 使用对应平台机制实现这些功能。X02/X03 仅记录平台实现替换，不再作为功能排除项；缺少实机验证也不构成排除理由。

## 本轮修正

- **终端搜索**：改为每个分屏独立的非模态搜索栏；软换行按逻辑行搜索；支持整词、正则、大小写和原始 Unicode 字形选区。修正 `ß/SS`、组合字符、输入法确认及窄分屏布局。数量统计与导航分开，超过 5,000 条仍可前后循环；从终端实时选区读取锚点，覆盖重排、裁剪及旧选区消失。
- **SSH 路由**：补齐配置内嵌套 ProxyJump/ProxyCommand；跳板使用自己的账号和端口配置，显式链优先。修复 ProxyCommand 管道远端地址无效导致主机密钥检查失败；补齐 `%n` 原始别名。三层真实 SSH 握手、循环/深度保护和凭据隔离回归通过。
- **FTP 与续传边界**：MLSD 行无法解析时回退 LIST，再回退 NLST；名称列表显示未知类型并支持目录探测，失败保留原路径。拒绝无效 UTF-8，补齐 MLSD 链接识别。SFTP 缺少类型信息时拒绝断点续传，不创建或发布临时片段。
- **同步策略**：手动模式禁止后台自动入口；修改配置不再绕过“失败后暂停”；失败状态跨重启保留；取消同时清理排队任务，再按已保存策略安排后续检查。错误建议使用当前目标的失败记录。
- **内存回收**：关闭与跨窗口迁移清除底层切片的旧标签/窗口/认证引用；所有窗口没有标签时延迟 2 秒在后台归还 Go 堆，重新打开则取消。结束但未关闭的标签保留历史。弱引用回归证明关闭标签可被 GC 回收。
- **图片粘贴**：接入纯 Go HEIC 解码，覆盖容器旋转/镜像/裁剪、网格、透明度及真实 10 位像素。转换时保留 RGB/灰度 ICC、PNG HDR 及 HEIC 色域/传递函数，限制颜色配置大小并拒绝不匹配的配置。锁定或窗口退出后不继续保存/粘贴；处理文件混选、EXIF 方向、上传私有权限、取消与上下文变化。
- **会话与窗口交互**：快速切换增加范围并按身份保留选择；补齐未保存本机会话的标题继承；退出全心专注后保留普通全屏；连接详情复制保持输入焦点。
- **状态与文件展示**：纯控制序列不再触发未读提示；文件类别对齐脚本、表格、安装包等分类；文件标签只展示唯一解析 IP；连接详情明确区分配置主机与实际 TCP 对端。
- **悬停详情**：输入、中文输入法、面板外点击/滚动、失焦/隐藏及详情变化时立即关闭；再次进入标签才重新显示。卡片内复制和滚动保持显示与原输入焦点，输入事件继续正常传递。
- **终端内图片**：发现原先禁用的 Kitty 图像能力并接入直接传输，支持 RGB/RGBA/PNG、分片和压缩；绘制裁剪、缩放、透明度及层级，随终端滚动/缩放更新。修复裁剪串色、同尺寸替换缓存失效和图片遮住光标；同步刷新期间保持旧画面，删除或关闭释放缓存。
- **主题扩展色**：按 SwiftTerm 默认 Lab 策略生成 256 色表，保留前 16 色，浅色主题保持明暗锚点顺序。OSC 10/11 改色后同步重建并清除旧色表覆盖，同包后续查询读取新结果；OSC 104 恢复最新派生值。切换主题也会清除旧的程序前景、背景和光标颜色覆盖。已知主题在连接读取前初始化，避免首帧覆盖已收到的远端背景色和光标对比色。

- **终端重置**：接入 DECSTR，恢复输入模式、滚动边界、文字属性、保存光标和派生色表，保留内容、历史、活动屏、图片及鼠标/粘贴模式。RIS 清屏并保留颜色覆盖、标题、光标可见性和形状，结束同步刷新。保存/恢复光标补齐换行、左右边界和反向换行模式。完全重置重建主屏历史，保留备用屏文字和保存光标；清除图片、两屏键盘状态及旧提示符标记。1047/1049 在退出时清屏，重复进入不误清文字或图片；清屏保留该屏保存光标和键盘栈。

- **双屏布局状态**：主屏与备用屏独立保存制表位和滚动边界；关闭左右边界模式后重新开启恢复原设置，设置边界不额外移动光标。缩放保留已有制表位并从最后锚点延伸，完全重置只重建主屏制表位。窗口缩小时将水平边界限制在有效网格内，避免复刻 Swift 残留越界边界的风险。

- **布局参数**：区分省略、显式零及尾部分号；支持单列/反向边界归一化，保留无边界模式时带参数保存光标、无效滚动范围仍归位的行为。零计数 Tab 按一步处理，后退 Tab 不受左边界限制，正确清除待换行状态。绝对光标定位只按屏宽截断，修正先前把右边界用于定位的错误预期。

- **输入解码**：按 SwiftTerm 消耗非法 UTF-8 的预期字节数，再回退显示首字节的 Latin-1 字符；普通 C0 执行后保留未完字符，ESC 丢弃未完字符。有效字符、非法序列与任意分块采用相同结果。纯 ASCII 保留原有快速路径；原始/编码 C1 在普通文本中不执行控制命令。DEL 统一忽略，不复刻 Swift ASCII 快路径按分块差异占列的缺陷。

- **控制字符串**：按 SwiftTerm 限定未完成指令中的 C1 执行范围；NEL 先按原点模式归列再滚动，LNM 归列也按原点模式处理。APC 支持 BEL 结束、普通 C0 忽略与 CAN/SUB 取消；取消不提交图形，并保留先前已接受的上传分片。SOS/PM 单独忽略，不再误执行其中的 Kitty 指令。

- **光标移动**：区分 CUP/HVP/CHA/HPA/VPA/HPR/VPR 的原点与边界规则，修复单轴移动重复加偏移。CUB 使用自身左右边界，不再套用退格的反向换行；CUU/VPA 保留行尾待换行状态，CNL/CPL 保留逻辑左边界。忽略额外参数、零按默认值处理，超参数上限不执行；CHA 极端越界列限制在有效网格内。

- **文本编辑与显式滚动**：对齐 ICH/DCH/ECH/IL/DL/SU/SD 的默认值、额外参数、光标和待换行规则。显式滚动不再新增历史，空白使用默认颜色而不改变当前 SGR；普通换行继续保留历史。插入/删除行保留移动内容内部的软换行，只切断新的行接缝。局部区域限制在有效网格内，不复制 Swift 行操作越界和 ICH 行尾取模缺陷；宽字符边缘仍维持完整字形约束。

- **擦除、整列操作与空白搜索**：补齐 DECIC/DECDC 的区域判断和不同空白属性；EL/ED 接受额外参数、保留待换行，并按指令处理逻辑行接缝。修复整行擦空后复制出现额外换行、搜索丢失内部空白的问题；长于 16 码点的字形簇改为按原生长度读取，避免丢成空格。

- **双宽与双高行**：接入 ESC #3/#4/#5/#6 的行状态，缩放文字、图片、选区及光标；双高上下半行独立裁剪。行移动、擦除、历史、双屏和重排保留对应状态，VT 导出可重放。修复 GPU/软件绘制器忽略字形目标尺寸的问题；双宽鼠标按显示位置选取和上报。

- **校准图案**：DECALN 只填充带当前颜色的 `E`，保留行样式、图片、边界、原点和当前文字属性。清除旧字形簇与单元格链接，后续输入仍沿用原超链接及 SGR；保存的光标不变。非零原点下仅填充有效可见行，保留历史和原点前内容。

- **内联图片**：接入 OSC 1337 File 的 PNG/JPEG/GIF/BMP/TIFF/WebP，支持自动、像素、单元格和百分比尺寸，保留横向光标并逐行附着。补齐滚动、双缓冲屏、软重置保留、清屏及完全重置删除；Kitty 指令不能误删内联图片。连接读取前初始化像素尺寸，避免首帧前丢图。普通行图片已独立于 Kitty 缓存；OSC 1337 EXIF 旋转/镜像已补齐；色彩、更多格式及接收预算仍有差异。

- **Sixel**：新增 DCS 图像接收和 RGB/HLS 解码，支持重复列、透明叠加、换行与宽度自适应；使用主题基础色表，图片内改色不泄露到下一张。按行滚动、保留横向光标，取消或超限不显示残缺图片，后续命令继续正常处理。修正 HLS 端点舍入和末尾单列丢图；仍不在 DA 中声明支持。

- **图片缓存与接收**：内联/Sixel 行图片不再计入 Kitty 4 MiB 配额，也不会被 Kitty 淘汰误删；解码尺寸单独校验，支持超过缓存额度的行图片。修正 OSC 1337 仍用 2 KiB 固定控制序列缓冲导致较大图片被丢弃的问题，改为有界动态接收。删除历史时先清理对应图片条带，最后一行移除后回收原生像素；内存统计仍计入独立行图片。

- **Kitty 缓存与画面**：同 ID 再传输、上传失败/尚未结束、缓存淘汰均保留已显示画面；缓存和显示内容分别管理，删除或历史裁剪后释放旧像素。PNG 按编码字节计量，原始图片按 RGBA 大小计量，按最近访问顺序淘汰。新图也参与淘汰，超过缓存额度仍可完成本次显示。绘制使用原始协议 ID 和位置创建顺序，内部保存的旧图片不会盖住新画面。协议缓存、编号映射、配额和未完上传已统一到终端；跨屏调取、替换及 ID/范围/层级删除共同生效。屏间共享不可变像素，最后引用删除后释放，内存统计不重复计量。

- **图片身份与应答**：客户端 ID 与内部图片 ID 冲突时迁移私有记录，保留画面和原始身份。编号独立映射到当前图片，按编号删除不会误删历史同编号图片；显式 ID 更新后保留编号别名，缓存淘汰后撤销。自动 ID 使用终端序列，匿名图片不占协议缓存。补齐无 ID 查询、编号优先查找及 ID 回退、静默成功/失败应答、分片继承首块静默设置。

- **清屏图片生命周期**：显式 ED 2 清除活动和备用缓冲区全部行的图片，包括历史区，保留文字历史。备用屏活动时保留主屏行图片；局部擦除和内部屏幕切换不触发跨屏清理。提示符清屏不再额外滚入历史。同时清除全局 Kitty 缓存但保留未完上传；备用屏重入清理旧显示和无引用缓存。

工作区还包含前续工作已实现的置顶、标题设置、同步内容选择、图片粘贴、Cascadia 字体、歧义字符宽度扩展及外部程序 IPC。本轮完整测试覆盖当前合并工作区，不把这些全部记为本轮首次新增。
